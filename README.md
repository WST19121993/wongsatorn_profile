# Wongsatorn Online CV

Static online CV / vCard built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` - page structure
- `style.css` - visual design and responsive layout
- `script.js` - editable profile data and interactions
- `assets/Wongsatorn_Resume.pdf` - downloadable resume
- `assets/profile-photo.png` - profile image placeholder

## Edit Profile Content

Open `script.js` and update the `profile` object. Timeline, projects, skills, education, language, and contact items render automatically from that data.

## Preview

Open `index.html` directly in a browser.

## Deploy

Upload the whole folder to any static host such as GitHub Pages, Netlify, Vercel, Cloudflare Pages, or a normal web server.
